## Changes

- Improved Esc interruption for foreground tools and agent calls, including pending MCP operations and responses that have not yet returned. Fixed a permission-check error path that could incorrectly report a user interruption without a cancellation request.
- Improved multi-agent orchestration: task IDs bind agent results to the intended task, completed reports mentioning an old error no longer trigger an automatic failure, and an isolated agent request in an empty `git init` repository no longer loops on the unresolved `HEAD` error. Implicit worktree isolation falls back to the current directory with a warning; explicitly requested isolation explains that an initial commit is required.
- Improved MCP enable/disable feedback and refreshed server details after changes. Updated OpenAI-compatible streaming and provider error handling, and aligned bundled documentation with current runtime behavior.

## Verification

The five native packages were built on a Windows x64 host. Archive contents, manifests, hashes, bundled offline docs, install scripts, and MCP examples were verified. The Windows executable, archive, and install/uninstall smoke checks passed. Linux and macOS executables were not run on target hosts in this release build.

The bundled build verification and compatibility TypeScript typecheck passed. No additional full test suite or live MCP/sub-agent interaction run was performed for this release candidate.

## macOS Gatekeeper Notice

This macOS package has not been Developer ID signed or Apple notarized. If macOS says `juhex` is damaged or cannot be opened, remove quarantine from the extracted release directory or installed directory, then run `juhex --version` again.

The macOS installer prints exact commands for the current install paths.
