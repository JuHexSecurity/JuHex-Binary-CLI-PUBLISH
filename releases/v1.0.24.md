# JuHex Binary CLI v1.0.24

## Native Packages

Download the five native archives and `SHA256SUMS.txt` from the GitHub Release for tag `v1.0.24`.

## Changes

- Fixed image paste failures leaving the prompt stuck in `Pasting text...`; image decode errors now release the paste state and clipboard commands have a bounded timeout.
- Added elapsed-time reporting to compact progress so long PreCompact hooks and summary requests remain observable instead of appearing frozen.
- Included the current backend telemetry counter normalization and device duration refresh fixes in the development repository; backend archives remain separate from the public CLI release.

## Verification

All five native targets were compiled on a Windows x64 host. Archive contents, manifests, hashes, bundled offline docs, install scripts, and MCP examples were verified. The Windows executable, archive, and install/uninstall smoke checks passed. Linux and macOS executables were archive-verified but not executed on their target hosts.

The verified build, compatibility TypeScript check, and focused compact/paste checks passed.
