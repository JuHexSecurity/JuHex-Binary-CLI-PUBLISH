## Changes

- Improved CLI telemetry provider classification so normal startup uses the active provider profile before stale shell environment variables, while explicit `--provider` and host-managed sessions keep higher priority.
- Normalized provider telemetry without leaking custom profile names, profile IDs, endpoints, API key names, tokens, prompts, transcripts, tool output, or MCP configuration.
- Added Provider Profile network handling for "Force direct connection"; entering `yes` stores `network.disableProxy: true`, while empty, `no`, `false`, or other values leave the field unset.
- Sanitized legacy `network.disableProxy: false` provider settings so default network configuration is not saved as a behavior-changing object.
- Included the latest backend-compatible session duration telemetry fixes in the matching source build; backend deployment packages are distributed separately and are not included in this public CLI release.

## macOS Gatekeeper Notice

This macOS package has not been Developer ID signed or Apple notarized. If macOS says `juhex` is damaged or cannot be opened, remove quarantine from the extracted release directory or installed directory, then run `juhex --version` again.

The macOS installer prints exact commands for the current install paths.
