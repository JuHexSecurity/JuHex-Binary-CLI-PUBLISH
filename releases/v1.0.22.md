## Changes

- Fixed DeepSeek official OpenAI-compatible image handling. When the active endpoint is `api.deepseek.com`, pasted image input is rejected before the request is sent, with a clear DeepSeek image unsupported message instead of a misleading tool-calling compatibility error.
- Fixed OpenAI-compatible Ctrl+C handling during the initial POST phase. User aborts are normalized to `APIUserAbortError`, so interrupted DeepSeek/OpenAI-compatible turns no longer render as `API Error: Please wait a moment and try again.`
- Improved `/mcp` Enable/Disable feedback. The MCP detail screen now shows spinner feedback while enabling or disabling a server and refreshes detail state from the latest MCP client/config/transport, avoiding stale disabled or stale transport views.
- Included the Force direct connection / `disableProxy` behavior fixes from v1.0.21 in this rebuilt native release: only `yes`/`true`/`1`/`y`/`on` stores `network.disableProxy: true`; empty, `no`, `false`, or other values leave the profile on default network behavior.
- Rebuilt native packages with the latest compiled knowledge index and bundled offline docs.

This macOS package has not been Developer ID signed or Apple notarized. If macOS says `juhex` is damaged or cannot be opened, remove quarantine from the extracted release directory or installed directory, then run `juhex --version` again.
